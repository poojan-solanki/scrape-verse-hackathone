# Get browser session

> **Official Source**: [https://docs.brightdata.com/api-reference/browser-api/get-session](https://docs.brightdata.com/api-reference/browser-api/get-session)
> **Category**: `scraping-automation`

---

GET /browser_sessions/{session_id}
Use the Bright Data Browser API to get a Browser Session. GET /browser_sessions/{session_id} returns 200 OK with session metadata as JSON.
