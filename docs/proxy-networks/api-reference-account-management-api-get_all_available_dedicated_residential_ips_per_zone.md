# Get available dedicated IPs per zone

> **Official Source**: [https://docs.brightdata.com/api-reference/account-management-api/Get_all_available_dedicated_residential_IPs_per_Zone](https://docs.brightdata.com/api-reference/account-management-api/Get_all_available_dedicated_residential_IPs_per_Zone)
> **Category**: `proxy-networks`

---

api-reference/openapi GET /zone/route_vips
Use the Bright Data Account Management API to get available dedicated IPs per Zone via GET /zone/route_vips, returning JSON zone or account data with 200 OK.

<Tip>
  Paste your API key to the authorization field. To get an API key, [Create an account](https://brightdata.com/?hs_signup=1\&utm_source=docs\&utm_campaign=playground) and learn [how to generate an API key](/api-reference/authentication#how-do-i-generate-a-new-api-key%3F)
</Tip>

<Warning>Only works with residential dedicated zone</Warning>
