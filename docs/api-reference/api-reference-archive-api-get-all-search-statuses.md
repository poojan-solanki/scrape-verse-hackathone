# Get all search statuses

api-reference/web-archive-api GET /webarchive/searches
Use the Bright Data Marketplace Archive API to get All Search Statuses. GET /webarchive/searches manages web archive snapshots; returns 200 OK with JSON status.

<Info>
  Starting **March 26, 2026**, the hot storage retention period changed from 48 hours to 24 hours.
</Info>
