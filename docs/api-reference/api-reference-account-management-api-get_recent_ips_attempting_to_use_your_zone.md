# Recent IPs attempting to use your zone

> **Official Source**: [https://docs.brightdata.com/api-reference/account-management-api/Get_recent_IPs_attempting_to_use_your_Zone](https://docs.brightdata.com/api-reference/account-management-api/Get_recent_IPs_attempting_to_use_your_Zone)
> **Category**: `api-reference`

api-reference/openapi GET /zone/recent_ips
Use the Bright Data Account Management API to recent IPs attempting to use your Zone via GET /zone/recent_ips, returning JSON zone or account data with 200 OK.

<Tip>
  Paste your API key to the authorization field. To get an API key, [Create an account](https://brightdata.com/?hs_signup=1\&utm_source=docs\&utm_campaign=playground) and learn [how to generate an API key](/api-reference/authentication#how-do-i-generate-a-new-api-key%3F)
</Tip>
