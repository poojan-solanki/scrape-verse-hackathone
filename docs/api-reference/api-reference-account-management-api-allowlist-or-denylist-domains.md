# Allowlist/denylist domain(s)

> **Official Source**: [https://docs.brightdata.com/api-reference/account-management-api/allowlist-or-denylist-domains](https://docs.brightdata.com/api-reference/account-management-api/allowlist-or-denylist-domains)
> **Category**: `api-reference`

---

api-reference/openapi POST /zone/domain_perm
Use the Bright Data Account Management API to allowlist/Denylist Domain(s). POST /zone/domain_perm returns 200 OK with zone or account JSON.

<Warning>Only users with **Admin** or **Ops** roles can perform this action.</Warning>

<Warning> **Warning:** This API can modify your account settings, damage your operations or incur charges.</Warning>
