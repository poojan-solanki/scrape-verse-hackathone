# Allowlist IP(s)

> **Official Source**: [https://docs.brightdata.com/api-reference/account-management-api/allowlist-ip](https://docs.brightdata.com/api-reference/account-management-api/allowlist-ip)
> **Category**: `api-reference`

api-reference/openapi POST /zone/whitelist
Use the Bright Data Account Management API to allowlist IP(s). POST /zone/whitelist returns 200 OK with zone or account configuration data as JSON.

<Warning>Only users with **Admin** or **Ops** roles can perform this action.</Warning>

<Warning> **Warning:** This API can modify your account settings, damage your operations or incur charges.</Warning>
