# List of denylisted IPs for a zone

> **Official Source**: [https://docs.brightdata.com/api-reference/account-management-api/zone-ip-denylist](https://docs.brightdata.com/api-reference/account-management-api/zone-ip-denylist)
> **Category**: `api-reference`

---

api-reference/openapi GET /zone/blacklist
Use the Bright Data Account Management API to list of denylisted IPs for a zone. GET /zone/blacklist returns 200 OK with zone or account JSON.

<Tip>
  Paste your API key to the authorization field. To get an API key, [Create an account](https://brightdata.com/?hs_signup=1\&utm_source=docs\&utm_campaign=playground) and learn [how to generate an API key](/api-reference/authentication#how-do-i-generate-a-new-api-key%3F)
</Tip>
