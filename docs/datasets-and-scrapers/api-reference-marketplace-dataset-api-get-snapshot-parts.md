# Get snapshot parts

> **Official Source**: [https://docs.brightdata.com/api-reference/marketplace-dataset-api/get-snapshot-parts](https://docs.brightdata.com/api-reference/marketplace-dataset-api/get-snapshot-parts)
> **Category**: `datasets-and-scrapers`

---

api-reference/dca-api GET /datasets/snapshots/{id}/parts
Use the Bright Data Marketplace Dataset API to get Snapshot Parts. GET /datasets/snapshots/{id}/parts returns 200 OK with snapshot metadata as JSON.
