# Get all scrapers

> **Official Source**: [https://docs.brightdata.com/api-reference/scrapers/management-apis/get-scrapers](https://docs.brightdata.com/api-reference/scrapers/management-apis/get-scrapers)
> **Category**: `datasets-and-scrapers`

---

api-reference/dca-api get /datasets/v3/scrapers
Use the Bright Data Web Scraper API to list every scraper on your account. GET /datasets/v3/scrapers returns each scraper's dataset ID and name as JSON.
