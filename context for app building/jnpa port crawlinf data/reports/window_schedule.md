# JNPA Window Schedule

## Fixed Berthing Window Schedule at JNPA

The Window Schedule page contains a PDF document (29 kb) with the Fixed Berthing Window Schedule.

### About Window Schedule
- JNPA operates a Fixed Berthing Window System
- This assigns specific time windows to shipping lines for berthing their vessels
- Each terminal has allocated windows for different services/lines
- Published as a downloadable document (updated periodically)

### Significance for App
- Window schedule tells shipping lines WHEN their vessel is expected to berth
- Deviations from window = delays = cost implications
- Historical window vs actual berth data = reliability scoring
- Key metric: Window Hit Rate (% of vessels berthing within scheduled window)

### Key Terminals with Windows
1. NSICT (Nhava Sheva International Container Terminal)
2. GTICT (Gateway Terminals India - APMT)
3. BMCT (Bharat Mumbai Container Terminals)
4. NSIGT (Nhava Sheva International Gateway Terminal)
5. JNPCT (JNPA Container Terminal - Formerly NSFT)
